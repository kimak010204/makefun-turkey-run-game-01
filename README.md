Gobble Dash — a complete original 2D turkey escape runner: sprint through an autumn farm as a turkey fleeing Thanksgiving dinner, outrun the knife-waving farmer, leap ovens and dodge carving knives, gobble corn for points, and reach the safe forest. Title screen, live HUD with score, distance and lives, caught and escaped end screens with instant restart, plus synthesized gobbles, screen shake and falling leaves.

## Run it

```sh
python3 -m http.server 8000 --directory game
```
